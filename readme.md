# Hangman Game 🎮  

[![Node.js](https://img.shields.io/badge/Node.js-16%2B-green)](https://nodejs.org/)  
[![Express.js](https://img.shields.io/badge/Express.js-%5E4.17.1-lightgrey)](https://expressjs.com/)  
[![Jest Tests](https://img.shields.io/badge/tests-passing-brightgreen)](https://jestjs.io/)  
[![License](https://img.shields.io/badge/license-MIT-blue)](LICENSE)  

Un projet simple pour créer le célèbre jeu du **pendu** en JavaScript.  
Ce projet met l'accent sur les **bonnes pratiques de test** grâce à une approche orientée **Test-Driven Development (TDD)**.  

---

## 🚀 Fonctionnalités  

- 🕹️ **Jouer au pendu** directement depuis votre navigateur.  
- ✅ **Tests robustes** écrits avec Jest pour valider la logique du jeu.  
- 📂 **Organisation claire du projet** avec des modules et des fichiers bien structurés.  
- 🌐 **Interface interactive** rendue avec EJS.  

---

## 📦 Installation  

1. Clonez le dépôt :  
   ```bash
   git clone https://github.com/KeyRoZ73210/javascript-courses-quality-and-test.git
   cd hangman-game

2. Installez les dépendances : 
   ```bash
   npm install

3. Configurez le fichier .env :  
   ```bash
   cp .env.example .env

4. Démarrez le serveur :  
   ```bash
   npm start

---

## . 📁 Structure du projet

Ce projet utilise Jest pour les tests unitaires.

1. Architecture :  
   ```bash
    ├── public/            # Fichiers statiques (HTML, CSS, JS client)
    ├── views/             # Templates EJS pour l'interface du jeu

    ├── game.js            # Logique principale du jeu
    ├── tools.js           # Fonctions utilitaires
    ├── index.js           # Serveur Express et gestion des routes
    ├── .env.example       # Exemple de configuration d'environnement
